# 3D 霓虹贪吃蛇

一个适合电脑端游玩的真实 WebGL 3D 贪吃蛇小游戏，使用原生 HTML、CSS 和 JavaScript 实现，不依赖外部 3D 库。

## 特色

- WebGL 透视相机和实时光照
- 真实 3D 方块蛇身和悬浮能量球
- 霓虹光效、玻璃面板和粒子爆发
- 本地最高分记录

## 玩法

- 用方向键或 `W` `A` `S` `D` 控制移动方向
- 按 `Space` 开始或暂停
- 按 `R` 重新开始
- 吃到能量果实可获得分数，分数越高速度越快
- 撞到墙壁或蛇身会结束游戏

## 运行

直接在浏览器中打开 `index.html` 即可开始游戏。
